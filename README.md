# AI QueueSense 🚀
### **Smarter Queues. Shorter Waits.**

> Real-time campus queue intelligence powered by computer vision crowd density analysis and AI-assisted wait time prediction.

---

## 📌 Project Overview

**AI QueueSense** is an enterprise-grade campus queue management platform designed to monitor crowd density, predict waiting times, and optimize service efficiency across campus counters (Canteen, Administrative Office, Library, Student Services, Fee Counter, Transport Office).

---

## ✨ Features

- 👁️ **Computer Vision Frame Processing**: Anonymous YOLOv8-style object detection framework.
- ⏱️ **AI Wait Time Forecasts**: Dynamic regression models estimating wait duration based on live inflow velocity.
- 🔒 **Privacy-First (Zero Biometrics)**: 100% anonymous numerical counting. No facial recognition or identity tracking.
- 🎓 **Student Portal**: Live crowd counts, status badges (Low, Medium, High), and recommended low-congestion visit windows (*e.g. "Try 3:30 PM - 4:00 PM"*).
- ⚙️ **Staff Command Center**: Live camera supervision, proactive surge alert notifications, and operational action dispatching.
- 🗺️ **Interactive Campus Map**: Color-coded crowd density layout.
- 📊 **Recharts Analytics Suite**: Hourly inflow heatmaps, peak volume analysis, and location load comparison.
- 🔔 **Smart Alert Center**: Automated threshold escalation notifications.
- 🎛️ **Demo Mode**: Built-in reactive simulation engine for live presentations and judge evaluations.

---

## 🛠️ Technology Stack

- **Framework**: Next.js 15+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Data Visualization**: Recharts
- **Icons**: Lucide React
- **State Management**: React Context API

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sanjaysharmasabari-byte/AI-QueueSense.git
   cd AI-QueueSense
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in Browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

---

## 🛡️ Privacy Guarantee

AI QueueSense processes pixel bounding boxes in-memory only. Video streams are not stored, and facial features are never extracted or saved.
